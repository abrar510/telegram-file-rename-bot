
# Telegram File Rename Bot

Telegram bot for renaming files and applying custom thumbnails.

## Features

- Receive forwarded files
- Rename files
- Add custom JPEG thumbnails
- Skip thumbnail
- Cancel operation
- Render Background Worker deployment

## Environment Variables

- API_ID
- API_HASH
- BOT_TOKEN

## Install

pip install -r requirements.txt

## Run

python bot.py
